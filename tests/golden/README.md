# Golden-харнесс: сверка с оригинальным PlantUML

Этот каталог обеспечивает **измеримую** проверку совместимости с PlantUML —
то, чего в проекте не было: заявление «100% совместимость» ничем не
подтверждалось, а `tests/visual/` не использовался ни одним тестом.

## Состав

```
tests/golden/
├── cases/          # исходники .puml, для которых снимаются эталоны
├── reference/      # эталонные SVG с plantuml.com + metadata.json
├── baseline.json   # зафиксированный текущий уровень расхождений
├── fetch_references.py
└── README.md
```

## Как получить эталоны

```bash
python3 tests/golden/fetch_references.py           # только отсутствующие
python3 tests/golden/fetch_references.py --force   # перезаписать все
```

Скрипт обращается к `https://www.plantuml.com/plantuml/svg/`, кодируя
исходник в формате сервера (raw deflate + **собственный алфавит PlantUML**,
не стандартный base64), и сохраняет версию PlantUML в `metadata.json`.

Требуется браузерный `User-Agent`: без него сервер отвечает 403.

## Почему сравнение не байтовое

Байтовое совпадение недостижимо и не является полезной целью:

| Аспект | PlantUML | мы |
|--------|----------|-----|
| Порядок атрибутов | свой | свой |
| Стили | CSS-классы | инлайн-атрибуты |
| Наконечники стрелок | инлайновый `<polygon>` | `<marker>` |
| Инструкция версии | `<?plantuml 1.2026.9beta4?>` | отсутствует |
| Единицы размеров | `width="306px"` | `width="338.5"` |

Поэтому тесты сравнивают измеримые характеристики: габариты диаграммы,
наличие подписей, число потерянных подписей.

## Модель «храповика»

Фактическое расхождение сейчас составляет от 7% до 67%, поэтому тест не
требует совпадения сразу. Текущий разрыв зафиксирован в `baseline.json`,
и тест падает, только если расхождение **выросло**:

1. CI зелёный на текущем (неидеальном) состоянии;
2. регрессия геометрии не проходит незамеченной;
3. прогресс измерим — `baseline.json` уменьшается по мере работы над Фазой 4.

## Обновление baseline

После осознанного улучшения геометрии:

```bash
UPDATE_BASELINE=1 cargo test -p plantuml-core --test golden_tests
```

**Изменённый `baseline.json` нужно просмотреть глазами** — это и есть
свидетельство того, что разрыв сократился.

## Метрика прогресса

```bash
cargo test -p plantuml-core --test golden_tests golden_report -- --nocapture
```

Печатает суммарное расхождение по всем кейсам.
